⚙️ Pengaturan Firebase Firestore

Agar fitur Mabar Lintas HP Siswa berjalan online di Vercel, tempel konfigurasi Firebase Anda di bawah ini. Saat guru membuat QR Code / Direct Link, konfigurasi ini otomatis terbawa ke HP siswa!

Panduan Cepat Setup Firebase (Gratis 3 Menit):
  1. Buka console.firebase.google.com → Buat Project baru.
  2. Masuk ke menu Build → Firestore Database → Klik Create database → Pilih Start in test mode.
  3. Buka Project Settings (ikon gerigi) → Scroll ke Your apps → Klik ikon Web (</>).
  4. Salin seluruh blok const firebaseConfig = { ... }; (atau format JSON) lalu tempel di kolom di bawah ini.
